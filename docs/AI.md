# AI

`AIProvider` supports a development-only mock, a Gemini OpenAI-compatible adapter (`AI_PROVIDER=gemini`, `GEMINI_API_KEY`), and an OpenAI-compatible adapter selected by environment. Tasks cover FAQ, editable profile/team drafts, multilingual CV building, writing, work requests, and grounded talent search. Generated content is stored as a draft and requires user confirmation. Uploads and interactive AI forms require explicit consent to transmit the entered content to a third-party AI provider. Missing production credentials return an unavailable response rather than a simulated AI answer.

The system instruction forbids verification, dispute decisions, bans, money movement, authoritative accounting, and invented talent facts. Talent recommendations must receive database query results as grounding. Candidate data is drawn from verified profiles, but the model's natural-language claims are not yet independently checked against database fields; do not treat the assistant as a verified source of profile facts. Before launch, add schema-constrained responses, server-side grounding validation, PII retention controls, durable per-account quotas, safety evaluation, and provider-specific observability. Verify the Gemini free-tier privacy terms before sending real personal documents.
