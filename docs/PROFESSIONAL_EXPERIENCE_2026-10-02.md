# Professional profile, CV and portfolio review

Preview-only code; keep real payment processing disabled.

- Shared searchable Arabic/English profession catalogue (40 roles, eight groups), preferred-field chips, role-ranked tools, and ten languages with proficiency. Existing legacy values remain available to prevent data loss. Remove the narrow profile skill checklist and portfolio skills form; existing stored skills are preserved.
- Individual phone and email required in the form and API. Gaza phone format is exactly ten Western digits starting with 05. International clients retain international-phone support. Western numeral formatting across dates and amounts; explicit LTR native date/contact inputs.
- Location can be typed or suggested from browser GPS using a local GeoNames nearest-town catalogue. This is a coarse suggestion, not address verification; no coordinates are transmitted to a geocoding provider or saved. Review the suggested name.
- CV versions stored independently by language inside existing private profile_drafts JSON, with an original retained. UI locale selects content locale; translations require the existing external-AI consent. Consent and unsaved drafts survive locale changes in the same browser session, scoped to the authenticated user. AI suggestions are reviewable, do not erase omitted populated sections, and can be undone. Both print templates include real user-entered phone, email and professional links.
- Browser voice interview uses speech recognition and synthesis plus AI follow-up questions and structured extraction. Text interview remains available in unsupported browsers. Transcript and extracted fields must be reviewed and explicitly saved. Microphone and recognition availability depend on browser permissions/support.
- PDF positional text assembly keeps logical Unicode character order and joins adjacent fragments; normalize DOCX/PDF Unicode and numerals. Reject unreadable text instead of guessing facts. Scanned PDFs without a text layer and malformed font mappings need a readable replacement; OCR is not implemented in this patch.
- Avatar, team-member images, portfolio images, message images, and work-request images are re-encoded before storage, stripping metadata, limiting dimensions, targeting WebP and a 1.2MB ceiling. Original verification/evidence and project-delivery documents remain intact. Existing uploaded originals are not bulk-rewritten.
- Portfolio title 5–50 characters and description <=100 in client and API. Expand taxonomy with 29 additional categories and six-language translations. Catalogue migration is additive and does not change existing category IDs or records.

Validation: run npm run check and the disposable database harness, including professional-taxonomy.sql. Runtime and browser results are recorded during preview verification; do not treat provider prompts or successful builds as proof of voice hardware, every PDF font, or end-to-end OAuth support on a new preview domain.
